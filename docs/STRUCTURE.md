# Структура репозитория

## Папки:
- `tech-specs/` - технические спецификации
- `labs/` - лабораторные работы
  - `lab1/` - лабораторная работа 1
  - `lab2/` - лабораторная работа 2
  - и т.д.
- `coursework/` - курсовая работа
- `src/` - общий исходный код
- `docs/` - документация
- `tests/` - тесты

## Правила именования:
- Лабораторные: `lab1/`, `lab2/`, ...
- Отчеты: `report.md`
- Код: `main.py`, `app.java`, и т.д.
